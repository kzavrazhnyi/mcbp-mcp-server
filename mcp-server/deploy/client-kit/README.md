# Підключення до MCP-сервера mcbp-ai (Windows)

Комплект для машини **клієнта**. Сервер уже піднятий кимось іншим — тут лише три кроки.

Що вам мають видати:

| Що | Приклад | Звідки |
|---|---|---|
| Адреса сервера | `https://<адреса сервера>:8443/mcp` | адміністратор сервера |
| Токен доступу | довгий випадковий рядок | адміністратор (`new-token.cmd` на сервері) |
| Файл сертифіката | `mcbp-mcp.cer` | адміністратор — лише якщо адреса на `https` |

Токен — це ваш пароль до BAS: він зіставлений з конкретною обліковкою, і всі дії
в журналі реєстрації бази підуть від вашого імені. Не пересилайте його далі.

## Крок 1. Довіра до сертифіката (лише для `https`)

Покладіть `mcbp-mcp.cer` поруч із `trust-cert.cmd`, натисніть на скрипті правою
кнопкою → **Запуск від імені адміністратора**. Без прав адміністратора скрипт
одразу скаже про це і нічого не змінить.

Скрипт вносить сертифікат у сховище «Довірені кореневі центри сертифікації».
Якщо адреса сервера на `http://` — цей крок пропускається.

## Крок 2. Реєстрація сервера в Codex

Запустіть `setup-codex.cmd`. Він спитає адресу та токен (або візьміть їх
аргументами: `setup-codex.cmd https://<адреса сервера>:8443/mcp <токен>`).

Скрипт:

1. знаходить `codex.exe` у `PATH`, а якщо там немає — у
   `%LOCALAPPDATA%\OpenAI\Codex\bin\`;
2. зберігає токен у змінній оточення користувача `MCBP_TOKEN` (`setx`);
3. виконує `codex mcp add mcbp --url <адреса> --bearer-token-env-var MCBP_TOKEN`.

**Після цього закрийте вікно і відкрийте нове** — `setx` діє лише на нові процеси.

## Крок 3. Перевірка

```
codex mcp list
```

Сервер `mcbp` має бути у списку. Далі в Codex попросіть, наприклад, показати
перелік довідників — має відповісти база, а не помилка авторизації.

## Якщо не працює

| Симптом | Причина |
|---|---|
| `400 BAD_AUTHORIZATION` | токен не той або застарів — запитайте новий |
| помилка сертифіката / TLS | не виконано крок 1, або сертифікат виданий на іншу адресу |
| `codex.exe not found` | не встановлено Codex CLI |
| працювало, перестало після зміни токена | не перевідкрито термінал після `setx` |
| з'єднання не встановлюється | сервер вимкнено або закрито порт — до адміністратора |

## Claude Code замість Codex

Claude Code вміє довільні заголовки, тож токен передається так само —
заголовком `Authorization: Bearer <токен>`. Схема `Basic` з обліковкою BAS
теж і далі приймається.
